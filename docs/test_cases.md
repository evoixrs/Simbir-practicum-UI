# Тест-кейсы для Automation Test Store

**Объект тестирования:** https://automationteststore.com/

**Тип тестирования:** UI

**Инструменты автоматизации:** Python, pytest, Selenium WebDriver, Chrome

## TC-001: Проверка сортировки товаров в подкатегории Men > Fragrance Sets

**Цель:** Проверить, что в подкатегории `Men > Fragrance Sets` корректно работает сортировка товаров по имени и стоимости в обоих направлениях, а количество товаров после сортировки не изменяется.

**Приоритет:** High

**Предусловия:**
- Сайт https://automationteststore.com/ доступен.
- Пользователь находится на главной странице сайта.
- В подкатегории `Men > Fragrance Sets` отображается 5 товаров.

**Тестовые данные:**
- Категория: `Men`.
- Подкатегория: `Fragrance Sets`.
- Варианты сортировки:
  - `Name A - Z`;
  - `Name Z - A`;
  - `Price Low > High`;
  - `Price High > Low`.

| № | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Открыть сайт https://automationteststore.com/ | Главная страница сайта открыта |
| 2 | Перейти в категорию `Men` | Открыта страница категории `Men` |
| 3 | Перейти в подкатегорию `Fragrance Sets` | Открыта страница подкатегории `Men > Fragrance Sets` |
| 4 | Проверить количество товаров в подкатегории | В подкатегории отображается 5 товаров |
| 5 | Сохранить исходное количество товаров | Исходное количество товаров сохранено для дальнейших проверок |
| 6 | Выбрать сортировку `Name A - Z` | Количество товаров не изменилось. Товары отсортированы по названию от A до Z |
| 7 | Выбрать сортировку `Name Z - A` | Количество товаров не изменилось. Товары отсортированы по названию от Z до A |
| 8 | Выбрать сортировку `Price Low > High` | Количество товаров не изменилось. Товары отсортированы по цене от меньшей к большей |
| 9 | Выбрать сортировку `Price High > Low` | Количество товаров не изменилось. Товары отсортированы по цене от большей к меньшей |

**Итоговый ожидаемый результат:**
- Подкатегория `Men > Fragrance Sets` открывается корректно.
- В подкатегории отображается 5 товаров.
- После каждой сортировки количество товаров остается равным исходному.
- Сортировка `Name A - Z` работает корректно.
- Сортировка `Name Z - A` работает корректно.
- Сортировка `Price Low > High` работает корректно.
- Сортировка `Price High > Low` работает корректно.

## TC-002: Проверка поиска, добавления товаров в корзину и пересчета итоговой суммы

**Цель:** Проверить, что пользователь может найти товары по запросу `shirt`, отсортировать выдачу, добавить 2-й и 3-й товар в корзину со случайным количеством, удвоить количество самого дешевого товара и проверить итоговую сумму корзины.

**Приоритет:** High

**Предусловия:**
- Сайт https://automationteststore.com/ доступен.
- Пользователь находится на главной странице сайта.
- Корзина пуста.
- По поисковому запросу `shirt` отображается не менее 3 товаров.

**Тестовые данные:**
- Поисковый запрос: `shirt`.
- Сортировка: `Name A - Z`.
- Товары для добавления: 2-й и 3-й товар из блока `Products meeting the search criteria`.
- Количество товара: случайное число от 1 до 20.

| № | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Открыть https://automationteststore.com/ | Главная страница сайта открыта |
| 2 | Найти строку поиска и кликнуть в нее | Строка поиска активна, курсор установлен в поле |
| 3 | Ввести `shirt` и нажать `Enter` | Открылась страница результатов поиска |
| 4 | Проверить количество товаров в блоке `Products meeting the search criteria` | В блоке отображается не менее 3 товаров |
| 5 | В дропдауне `Sort By` выбрать `Name A - Z` | Товары отсортированы по названию от A до Z без учета регистра. Количество товаров не изменилось |
| 6 | Найти карточку 2-го товара и кликнуть на иконку добавления в корзину | Произошел переход на страницу товара, в URL присутствует id товара. Название и цена товара сохранены |
| 7 | В поле `Qty` ввести случайное число от 1 до 20. Запомнить введенное количество | Значение введено в поле |
| 8 | Нажать кнопку `Add to Cart` | Произошел автоматический переход в корзину |
| 9 | Вернуться на страницу результатов поиска, при необходимости нажав `Back` в браузере 2 раза | Открылась страница `Products meeting the search criteria`, товары отсортированы по имени A-Z |
| 10 | Найти карточку 3-го товара и кликнуть на иконку добавления в корзину | Произошел переход на страницу товара, в URL присутствует id товара. Название и цена товара сохранены |
| 11 | В поле `Qty` ввести случайное число от 1 до 20. Запомнить введенное количество | Значение введено в поле |
| 12 | Нажать кнопку `Add to Cart` | Произошел автоматический переход в корзину |
| 13 | Проверить состав корзины | В корзине ровно 2 позиции. Названия и количества совпадают с сохраненными данными |
| 14 | В столбце `Total` найти строку с наименьшей стоимостью | Самый дешевый товар определен |
| 15 | В столбце `Quantity` для самого дешевого товара прочитать текущее количество, очистить поле и ввести значение `текущее количество x 2` | Новое значение введено в поле |
| 16 | Нажать кнопку `Update` | Корзина обновилась. Количество самого дешевого товара увеличено в 2 раза, значение `Total` для этого товара пересчитано |
| 17 | В строке `Total` внизу страницы считать итоговую сумму и сравнить с суммой значений столбца `Total` по всем строкам | Итоговая сумма внизу страницы равна сумме всех значений столбца `Total` с точностью до `$0.01` |

**Итоговый ожидаемый результат:**
- Поиск по запросу `shirt` возвращает не менее 3 товаров.
- Сортировка `Name A - Z` применяется корректно.
- Количество товаров после сортировки не изменяется.
- 2-й и 3-й товары из выдачи добавлены в корзину со случайным количеством от 1 до 20.
- В корзине отображаются ровно 2 выбранных товара.
- Самый дешевый товар корректно найден по столбцу `Total`.
- Количество самого дешевого товара удвоено.
- Итоговая сумма корзины рассчитана корректно.
