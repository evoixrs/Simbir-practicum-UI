# Тест-кейсы для Automation Test Store



## TC-01: Сортировка товаров в подкатегории Men > Fragrance Sets

**Цель:** Проверить, что в подкатегории `Men > Fragrance Sets` корректно работает сортировка товаров по имени и стоимости в обоих направлениях, а количество товаров после сортировки не изменяется.

**Тестовые данные:**
- Категория: `Men`.
- Подкатегория: `Fragrance Sets`.
- Варианты сортировки:
  - `Name A - Z`;
  - `Name Z - A`;
  - `Price Low > High`;
  - `Price High > Low`.

| № | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Открыть сайт https://automationteststore.com/ | Главная страница сайта открыта |
| 2 | Навести курсор на категорию `Men` в главном меню | Отображается выпадающее меню с подкатегориями категории `Men` |
| 3 | В выпадающем меню кликнуть на подкатегорию `Fragrance Sets` | Открыта страница подкатегории `Men > Fragrance Sets`, отображаются товары внутри подкатегории |
| 4 | Проверить количество товаров в подкатегории | В подкатегории отображается не менее 4 товаров |
| 5 | Сохранить исходное количество товаров | Исходное количество товаров сохранено для дальнейших проверок |
| 6 | Выбрать сортировку `Name A - Z` | Количество товаров не изменилось. Товары отсортированы по названию от A до Z |
| 7 | Выбрать сортировку `Name Z - A` | Количество товаров не изменилось. Товары отсортированы по названию от Z до A |
| 8 | Выбрать сортировку `Price Low > High` | Количество товаров не изменилось. Товары отсортированы по цене от меньшей к большей |
| 9 | Выбрать сортировку `Price High > Low` | Количество товаров не изменилось. Товары отсортированы по цене от большей к меньшей |

**Ожидаемый результат:**
- Подкатегория `Men > Fragrance Sets` открывается корректно.
- В подкатегории отображается не менее 4 товаров.
- После каждой сортировки количество товаров остается равным исходному.
- Сортировка `Name A - Z` работает корректно.
- Сортировка `Name Z - A` работает корректно.
- Сортировка `Price Low > High` работает корректно.
- Сортировка `Price High > Low` работает корректно.

## TC-02: Поиск, добавления товаров в корзину и пересчета итоговой суммы

**Предусловия:**
- Корзина пуста.
- По поисковому запросу `shirt` отображается не менее 3 товаров.

**Тестовые данные:**
- Поисковый запрос: `shirt`.
- Сортировка: `Name A - Z`.
- Товары для добавления: 2-й и 3-й товар из блока `Products meeting the search criteria`.
- Количество товара: случайное число от 1 до 15, но не больше лимита товара, если он указан на странице товара.

| № | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Открыть https://automationteststore.com/ | Главная страница сайта открыта |
| 2 | Найти строку поиска и кликнуть в нее | Строка поиска активна, курсор установлен в поле |
| 3 | Ввести `shirt` и нажать `Enter` | Открылась страница результатов поиска |
| 4 | Проверить количество товаров в блоке `Products meeting the search criteria` | В блоке отображается не менее 3 товаров |
| 5 | В дропдауне `Sort By` выбрать `Name A - Z` | Товары отсортированы по названию от A до Z без учета регистра. Количество товаров не изменилось |
| 6 | Найти карточку 2-го товара и кликнуть на иконку добавления в корзину | Произошел переход на страницу товара, в URL присутствует id товара. Название и цена товара сохранены |
| 7 | В поле `Qty` ввести случайное число от 1 до 15, но не больше лимита товара, если он указан на странице товара. Запомнить введенное количество | Значение введено в поле |
| 8 | Нажать кнопку `Add to Cart` | Произошел автоматический переход в корзину |
| 9 | Вернуться на страницу результатов поиска, при необходимости нажав `Back` в браузере 2 раза | Открылась страница `Products meeting the search criteria`, товары отсортированы по имени A-Z |
| 10 | Найти карточку 3-го товара и кликнуть на иконку добавления в корзину | Произошел переход на страницу товара, в URL присутствует id товара. Название и цена товара сохранены |
| 11 | В поле `Qty` ввести случайное число от 1 до 15, но не больше лимита товара, если он указан на странице товара. Запомнить введенное количество | Значение введено в поле |
| 12 | Нажать кнопку `Add to Cart` | Произошел автоматический переход в корзину |
| 13 | Проверить состав корзины | В корзине ровно 2 позиции. Названия и количества совпадают с сохраненными данными |
| 14 | Внизу страницы считать и запомнить итоговую сумму `Total`: название строки имеет локатор `extra bold totalamout`, значение суммы имеет локатор `bold totalamout` | Итоговая сумма `Total` сохранена |
| 15 | В столбце `Total` найти строку с наименьшей стоимостью | Самый дешевый товар определен |
| 16 | В столбце `Quantity` для самого дешевого товара прочитать текущее количество, очистить поле и ввести значение `текущее количество x 2` | Новое значение введено в поле |
| 17 | Нажать кнопку `Update` | Корзина обновилась. Количество самого дешевого товара увеличено в 2 раза, значение `Total` для этого товара пересчитано |
| 18 | В строке `Total` внизу страницы считать итоговую сумму и сравнить с ожидаемой суммой после пересчета | Итоговая сумма `Total` внизу страницы равна сохраненному `Total` до обновления плюс прежнее значение `Total` строки самого дешевого товара с точностью до `$0.01` |

**Ожидаемый результат:**
- Поиск по запросу `shirt` возвращает не менее 3 товаров.
- Сортировка `Name A - Z` применяется корректно.
- Количество товаров после сортировки не изменяется.
- 2-й и 3-й товары из выдачи добавлены в корзину со случайным количеством от 1 до 15 с учетом лимита товара на странице товара.
- В корзине отображаются ровно 2 выбранных товара.
- Самый дешевый товар корректно найден по столбцу `Total`.
- Количество самого дешевого товара удвоено.
- Итоговая сумма корзины рассчитана корректно.

## TC-03: Состояние корзины после удаления четных товаров

**Предусловия:**
- Корзина пуста.
- На главной странице отображается не менее 5 уникальных товаров.

**Тестовые данные:**
- Товары для добавления: 5 случайных уникальных товаров с главной страницы.
- Количество товара: случайное число от 1 до 20.
- Товары для удаления: товары на позициях 2 и 4 из исходного порядка строк корзины.

| № | Шаг | Ожидаемый результат |
|---|-----|---------------------|
| 1 | Открыть https://automationteststore.com/ | Главная страница сайта открыта |
| 2 | Проскроллить страницу вниз до секции с карточками товаров | Отображаются карточки товаров с иконками корзины в секциях `FEATURED`, `LATEST PRODUCTS`, `BESTSELLERS`, `SPECIALS` |
| 3 | Найти все ссылки на товары по атрибуту `href`, содержащему `product_id`, убрать дубликаты | Найдено не менее 5 уникальных товаров |
| 4 | Случайным образом выбрать 5 уникальных товаров из найденных | 5 уникальных товаров выбраны |
| 5 | Кликнуть на иконку корзины у карточки 1-го выбранного товара | Произошел переход на страницу товара, в URL присутствует `product_id`. Название и `Unit Price` товара сохранены |
| 6 | В поле `Qty` ввести случайное число от 1 до 20. Запомнить введенное количество | Значение введено в поле, `Total Price` пересчитан |
| 7 | Нажать кнопку `Add to Cart` | Произошел автоматический переход в корзину |
| 8 | Кликнуть кнопку `Home` в навигационном меню | Открылась главная страница сайта |
| 9 | Повторить шаги 5-8 для оставшихся 4 товаров | Каждый товар успешно добавлен. Запомнены название, `Unit Price` и количество всех 5 товаров |
| 10 | Нажать `CART` в шапке сайта | Открылась страница `Shopping Cart` |
| 11 | Проверить состав корзины | В таблице ровно 5 строк. Названия и количества совпадают с запомненными значениями |
| 12 | Зафиксировать порядок строк с позициями 1-5. Нажать кнопку `Remove` у товара на позиции 4 | Таблица обновилась. Товар на позиции 4 удален. В корзине 4 строки |
| 13 | Нажать кнопку `Remove` у товара на позиции 2 из исходного порядка | Таблица обновилась. Товар на позиции 2 удален. В корзине 3 строки |
| 14 | Проверить состав корзины | В таблице ровно 3 строки: бывшие позиции 1, 3 и 5. Удаленные товары не отображаются |
| 15 | Считать значения столбца `Total` для каждой из 3 строк и значение `Sub-Total` внизу страницы | Отображаются актуальные значения для всех строк |
| 16 | Вычислить ожидаемый `Sub-Total` как сумму значений столбца `Total` всех 3 строк | `Sub-Total` внизу страницы равен сумме столбца `Total` по всем строкам с точностью до `$0.01` |

**Ожидаемый результат:**
- В корзину добавлено 5 случайных уникальных товаров с главной страницы.
- Для каждого товара задано и сохранено случайное количество от 1 до 20.
- Из корзины удалены товары на позициях 2 и 4 из исходного порядка.
- В корзине остались товары, которые были на позициях 1, 3 и 5.
- Итоговая стоимость корзины рассчитана корректно.
